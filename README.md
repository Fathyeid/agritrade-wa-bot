# بوت واتساب أجري تريد 🌾

بوت واتساب مجاني بالكامل لخدمة سوق الحبوب: موجز يومي، أسعار، ورد على الأسئلة بالعامية المصرية.
بيشتغل على **رقم واتساب جانبي** عن طريق مكتبة Baileys (غير رسمية)، من غير ميتا ومن غير أي فلوس.

## التشغيل بيكلف كام؟

صفر جنيه. الاستضافة على Render (خطة مجانية، مش محتاجة كارت)،
وقاعدة البيانات هي نفس مشروع Supabase بتاع AgriTrade الموجود أصلاً.

## اللي البوت بيعمله

- **الاشتراك**: أي حد يبعت "اشتراك" يتسجل، و"إلغاء" يوقف الرسايل فورًا.
- **القايمة**: 1️⃣ موجز النهاردة (من جدول التقارير) — 2️⃣ الأسعار — 3️⃣ اسأل سؤال.
- **أسئلة حرة**: لو فيه مفتاح Gemini (مجاني) البوت بيرد بالعامية، ولو مفيش بيسجل السؤال.
- **أوامر الأدمن** (من رقم فتحي الأساسي بس):
  - `بث <الرسالة>` — إرسال لكل المشتركين (ببطء، برسالة كل 3–7 ثواني، حد أقصى 150).
  - `احصائيات` — عدد المشتركين.
  - `كود` — كود الربط الحالي لو احتجنا نعيد الربط.
- **حماية من الحظر**: البوت بيرد على اللي بيكلمه بس، مفيش رسايل لأرقام غريبة،
  مفيش جروبات، والبث بطيء ومتدرج. ده مش ضمان 100% — واتساب ممكن يحظر أي رقم
  شغال بمكتبة غير رسمية، عشان كده الرقم جانبي.

## خطوات النشر (مرة واحدة)

1. **قاعدة البيانات**: شغّل `schema.sql` في SQL Editor بتاع Supabase (بيضيف 3 جداول صغيرة).
2. **GitHub**: اعمل Repository جديد (public أو private) وارفع عليه الملفات دي.
3. **Render**: اعمل حساب مجاني على render.com (تسجيل بجوجل)، ثم New → Web Service → اختار الريبو.
   - الخطة Free، والـ `render.yaml` بيظبط الباقي تلقائيًا.
   - ضيف المتغيرات السرية في صفحة Environment:
     - `SUPABASE_SERVICE_ROLE_KEY` (مفتاح service role — سرّي، ميتحطش في الكود)
     - `ADMIN_SECRET` (أي كلمة سر طويلة — بتحمي صفحة كود الربط)
     - `GEMINI_API_KEY` (اختياري — للرد على الأسئلة)
   - ملاحظة: الساعات المجانية 750 ساعة في الشهر، وخدمة واحدة شغالة 24 ساعة بتستهلك ~744.
     البوت بيعمل ping لنفسه كل 10 دقايق عشان الخدمة متنامش.
4. **ربط الرقم** (آخر خطوة، وبموافقة فتحي):
   - افتح `https://<اسم-الخدمة>.onrender.com/pairing-code?key=<ADMIN_SECRET>` — هيطلعلك كود من 8 حروف.
   - على موبايل الرقم الجانبي: واتساب → الأجهزة المرتبطة → ربط جهاز → "الربط برقم الهاتف بدلًا من ذلك" → اكتب الكود.
   - خلاص، البوت شغال. الجلسة بتتحفظ في Supabase فلو السيرفر اتعاد تشغيله مش هيطلب ربط تاني.

## التشغيل محليًا (اختياري)

```bash
npm install
cp .env.example .env   # واملأ القيم
node index.js
```

للتجربة من غير ما يتصل بواتساب: `DRY_RUN=1 node index.js`

## حدود النسخة دي

- الاستضافة المجانية مش مضمونة 100% (ممكن وقفة دقايق في الشهر لو الساعات خلصت).
- لو الرقم اتحظر من واتساب (خطر معروف للمكاتب غير الرسمية)، بنعمل رقم جانبي جديد ونعيد الربط.
- الأسعار (اختيار 2) بتقرأ من جدول `prices` — لو اسم الجدول الحقيقي مختلف، غيّر `PRICES_TABLE`.
